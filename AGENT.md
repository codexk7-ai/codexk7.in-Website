# 46. ERROR HANDLING

If an implementation fails:

1. Read the actual error.
2. Identify the root cause.
3. Fix the smallest necessary surface.
4. Re-run the failed check.
5. Verify that the fix did not break another feature.

Do not hide errors.

Do not delete functionality simply because it causes an implementation problem.

---

# 47. DEPENDENCY POLICY

Before installing a dependency:

Ask:

1. Is it actually required?
2. Does the existing project already provide equivalent functionality?
3. Does it increase bundle size significantly?
4. Is it maintained?
5. Does it introduce security concerns?
6. Can the feature be implemented with existing dependencies?

Prefer existing dependencies.
